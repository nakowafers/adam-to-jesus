# Project Instructions: Adam to Jesus

This file contains foundational mandates for the "Adam to Jesus" project. These instructions take precedence over general workflows.

## Contextual Awareness

- **Pre-Step Validation:** Before proceeding with any implementation or strategic detour, you MUST check for and read the following core context files if they exist:
    - `REQUIREMENTS.md`: For functional and technical mandates.
    - `ARCHITECTURE.md`: For the edge-first technical stack and data flow patterns.
    - `DESIGN.md` (or specific `DESIGN_*.md` files): For visual identity and UI/UX standards.
- **Alignment:** Ensure all proposed changes align with the established vision, performance targets, and data strategies defined in these documents.

## Sourcing & Research Standards

- **Approved Sources:** All theological, historical, or lineage-related information MUST be sourced from either **Holy Scripture** or **peer-reviewed academic literature**.
- **Attribution:** Every new page, component, or data entry that introduces factual information must include explicit **references or links** to the original sources.
- **Verification:** When pulling data from APIs or external databases, verify the underlying source matches the criteria above before integration.
