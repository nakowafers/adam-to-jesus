# Issue Tracker Configuration: GitHub

Issues for this repository live in GitHub Issues for `nakowafers/adam-to-jesus`.

## Tooling

Use the GitHub CLI (`gh`) for all issue operations:

- **List issues**: `gh issue list`
- **View issue**: `gh issue view <number>`
- **Create issue**: `gh issue create --title "<title>" --body "<body>"`
- **Add comment**: `gh issue comment <number> --body "<comment>"`
- **Close issue**: `gh issue close <number>`

## Conventions

- Issues should include reproduction steps, expected behavior, and relevant file links where applicable.
- External PRs as a request surface: disabled by default.
